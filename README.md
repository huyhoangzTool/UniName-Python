# UniName Python

Công cụ web giúp chuyển tên thương hiệu thành logo ký tự (ASCII / Unicode Block / Khung terminal) để in ra console khi chạy chương trình Python.

**Dùng trực tiếp tại:** [uninamepython.vercel.app](https://uninamepython.vercel.app)

## Tính năng

- **4 kiểu ký tự:** 
  - Kí tự gạch (`/ \ _ |`)
  - Unicode Block (`█ ▀ ▄`)
  - Kí tự khung đôi (`╔ ═ ╗ ║ ╚ ╝`)
  - Khung kết hợp Block
- **Tùy chỉnh:** 
  - Bật/tắt chữ nghiêng
  - Chọn màu đơn hoặc phối màu Gradient
- **Copy nhanh:** Copy mỗi logo hoặc copy kèm đoạn code `print()` dùng cho Python.

## Ví dụ code xuất ra

```python
logo = """
  ____        _   _                 
 |  _ \\ _   _| |_| |__   ___  _ __  
 | |_) | | | | __| '_ \\ / _ \\| '_ \\ 
 |  __/| |_| | |_| | | | (_) | | | |
 |_|    \\__, |\\__|_| |_|\\___/|_| |_|
        |___/                       
"""
print(logo)
```
